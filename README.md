 Julia Kasperek — Portfolio

Personal portfolio website built with React, TypeScript, Tailwind CSS and Motion.

## Live Site
https://juliakasperek.github.io/Portfolio

## About
A responsive portfolio website showcasing my projects, experience, and skills as a fourth year Computer Science student at Western University.

## Features
- Responsive, mobile-first layout
- Scroll-triggered and spring animations (respects reduced-motion settings)
- Swipeable photo deck and draggable stickers and skill tiles
- Expandable experience timeline
- All content in one typed file: `src/data.ts`

## Built With
- [React](https://react.dev) + [TypeScript](https://www.typescriptlang.org)
- [Vite](https://vite.dev)
- [Tailwind CSS](https://tailwindcss.com)
- [Motion](https://motion.dev)

## Running Locally
```bash
npm install
npm run dev      # start a dev server with live reload
npm run build    # build the site into dist/
npm run preview  # preview the built site
```

## Updating Content
Edit `src/data.ts` — experience, projects, skills, education, and photos all live there.
Images go in `public/img/`.
